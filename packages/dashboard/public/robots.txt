# A cost control, not a privacy measure. Receipts are public and shareable by
# design — but with nothing cached, every /tx hit is a fresh ~130-call RPC
# analysis charged against the global hourly ceiling (see the rate limits in
# app/tx/[chain]/[hash]/receiptBody.tsx). A crawler that discovers a few shared
# receipt links and walks them exhausts that budget, and real visitors get the
# ceiling notice instead of a receipt.
#
# Disallow stops the fetch for crawlers that obey it. The matching
# X-Robots-Tag: noindex is set in next.config.mjs for crawlers that arrive from
# an external link rather than by crawling.
#
# ⚠️ THIS DOES NOT STOP LINK EXPANDERS. Measured 2026-08-11: Slack fetched
# /tx/... to build a message preview despite the Disallow below, rendering a
# receipt and spending a full analysis per expansion. Slack specifically is
# handled by unfurl_links/unfurl_media in lib/alerts.ts — but any chat app,
# and anyone pasting a receipt link into one, can still fetch this path.
# Treat the rules below as advisory, not as a spend control.
#
# /qa is dev-only and 404s in production, but is listed for the same reason.
# The index and /methodology are deliberately left crawlable.
User-agent: *
Disallow: /tx/
Disallow: /qa/
